Overview

What this course covers

This course teaches Docker from first container to multi-container apps, focusing on images, containers, volumes, networking, Compose, and practical habits for shipping containerized applications.

Build & run

Build and run containerized applications with Docker.

Modules

Course curriculum

Module 1 · Docker foundations and first container

Start with what containers solve, install Docker, and run your first container.

Lesson 1 What Docker is and why containers matterUnderstand how containers package apps and why they improve portability. Lesson 2 Install Docker and run your first containerSet up Docker locally and run a container from an existing image. Lesson 3 Images, containers, and the Docker CLI workflowLearn the relationship between images, running containers, and common CLI commands.

Module 2 · Images, layers, and Dockerfiles

Build images with Dockerfiles and understand how layers and caching work.

Lesson 4Build a Docker image with a DockerfileWrite a Dockerfile, build an image, and run a container from it. Lesson 5Understand image layers and cachingSee how each instruction creates a layer and how layer order affects build speed. Lesson 6Choose a base image and manage image sizePick appropriate base images and use multi-stage builds to keep images small.

Module 3 · Container lifecycle, data, and volumes

Control running containers and persist data safely outside the container filesystem.

Lesson 7Container lifecycle and essential commandsStart, stop, inspect, remove, and debug containers with practical commands. Lesson 8Persist data with volumes and bind mountsUse named volumes and bind mounts so data survives container restarts. Lesson 9Environment variables and container configurationPass configuration into containers with env vars and small config files.

Module 4 · Networking and multi-container apps with Compose

Connect containers with networks and describe multi-container apps with Docker Compose.

Lesson 10Docker networking basicsUnderstand bridge networks, port mapping, and container-to-container communication. Lesson 11Orchestrate multi-container apps with Docker ComposeDefine services, networks, and volumes in a compose file for local development.

Module 5 · Registry workflow and production-ready habits

Publish images to a registry and apply practical habits for safer container usage.

Lesson 12Push, pull, and production-ready container habitsUse Docker Hub or a private registry, tag images clearly, and follow non-root and minimal-image habits.
